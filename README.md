# 🚗 Auto Regions

> Система выбора и фильтрации автомобилей по регионам. Поиск региона по номерному знаку.

## 🧾 Описание

Auto Regions — это веб-приложение, позволяющее пользователям:
- Выбирать автомобили по регионам
- Просматривать информацию о доступных авто в выбранном регионе

## 🚀 Установка и запуск

### 1. Клонируйте репозиторий:
```bash
git clone https://github.com/VovanGod/autoRegions.git
cd autoRegions
```

### 2. Запуск
```bash
npm install
npm run start
```
